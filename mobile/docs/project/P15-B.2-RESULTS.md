A prova de causalidade está clara: o **TopHUD é o gerador do memory leak**.
Ao consumir useGameState() diretamente no escopo global e ser forçado a reconciliar 30 vezes por segundo, ele monta e desmonta virtualmente (ou re-avalia props inline de) uma árvore extensa de React Native Modals (AlertsDrawer, StabilityTooltip, TreasuryTooltip, PopulationTooltip, TerritoryTooltip, DevModeModal). 

Esta taxa de reconciliação de Modals (mesmo que com isible=false) gera sobrecarga de ViewRootImpl virtual e retenção de ponteiros no JSI, caracterizando um leak elástico onde o GC nunca consegue alcançar a taxa de alocação de sujeira.
