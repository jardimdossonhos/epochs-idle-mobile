## 5. Classificação de Causalidade (UI -> Memory Leak)

**HIPÓTESE ENFRAQUECIDA / REFUTADA.**
Embora a correção arquitetural via React.memo tenha sido um sucesso isolado do ponto de vista de reconciliação do React (reduzindo em ~33% a carga de rendering supérflua no header), a variação do agrupamento Unknown manteve-se virtualmente idêntica (~34 MB acumulados no mesmo período de simulação de 30x).

Isso atende ao seu rigor epistêmico: a duplicação de renders de UI de alta frequência pode ser um gargalo de CPU, mas **não é a causa primária material da retenção de memória no setor Unknown**.
